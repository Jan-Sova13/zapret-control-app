# Zapret Control App

Оконная оболочка для zapret (Flowseal/zapret-discord-youtube). Один .exe, ничего не ставит в систему:
пока программа открыта — работает обход, закрыл или она упала — всё выключается.

## Сборка (один раз)

1. Установи .NET 8 SDK: `winget install Microsoft.DotNet.SDK.8` (или скачай с dot.net).
2. Открой терминал в папке с проектом (где лежит `ZapretControl.csproj`) и выполни:

       dotnet publish -c Release

   Нужен интернет (скачается рантайм для упаковки в exe).
3. Готовый файл: `bin\Release\net8.0-windows\win-x64\publish\Zapret Control App.exe`
   Это самодостаточный exe (~50–70 МБ, внутри .NET), ставить .NET на целевой компьютер не нужно.
   Его можно скопировать куда угодно.

Windows может показать предупреждение SmartScreen (exe не подписан) — «Подробнее → Выполнить в любом случае».
Антивирус может ругаться на WinDivert из папки zapret — добавь папку zapret в исключения.

## Первый запуск

1. Программа просит права администратора (нужны WinDivert и автозапуск).
2. Вкладка «Настройки» → укажи папку zapret. Если у тебя её нет — укажи пустую папку (без кириллицы и не в OneDrive)
   и нажми «Обновить zapret»: скачается последний релиз.
3. Вкладка «Проверка стратегий (автоподбор)» → «Запустить автоподбор» (VPN на это время лучше выключить), выбери лучшую стратегию.
4. Кнопка «Включить».

## Тема

Три темы: светлая (белое/серое), тёмная (по умолчанию) и зелёная. Выбор — выпадающий список «Тема» справа от вкладок;
выбранная тема сохраняется в настройках.

## Масштаб

Интерфейс масштабируется по системному DPI (100%, 125%, 150% и т.д.). Масштаб определяется при запуске.

## Как это устроено

- Стратегии берутся прямо из `general*.bat`: программа читает из них аргументы `winws.exe` и подставляет пути,
  поэтому после обновления zapret новые стратегии появляются сами.
- `winws.exe` запускается как дочерний процесс в Job Object: если программа умерла (даже аварийно), winws убит системой.
- Драйвер WinDivert выгружается при остановке (только если он реально остановился и нет другого winws/службы zapret).
- TCP timestamps (нужны части стратегий) включаются на время работы и возвращаются; если программа упала —
  вернутся при следующем запуске.
- Автозапуск — задача планировщика `Zapret Control App` (запуск с правами администратора без UAC-окна). Снял галочку — задача удалена.
- Настройки: `%AppData%\Zapret Control App\settings.json`. Бэкапы старых списков при обновлении: `%AppData%\Zapret Control App\backup\`.
- Свои списки `*-user.txt` при обновлении сохраняются. Стоковые (`list-general.txt`, `ipset-all.txt` и др.) заменяются.
