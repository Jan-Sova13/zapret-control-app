# Zapret Control App

Оконная оболочка для zapret (Flowseal/zapret-discord-youtube). Один .exe, ничего не ставит в систему: пока программа открыта — работает обход, закрыл или она упала — всё выключается.

## Первый запуск

1. Программа **всегда** требует права администратора (нужны для WinDivert).
2. Вкладка «Настройки» → указать папку Zapret. Если Zapret не установлен — указать пустую папку (без кириллицы и не в OneDrive) и нажать «Обновить Zapret»: скачается последний релиз.
3. Вкладка «Проверка стратегий (автоподбор)» → «Запустить автоподбор» (VPN на это время лучше выключить), по результату выбрать лучшую стратегию.
4. Кнопка «Включить».

## Как это устроено

- Стратегии берутся прямо из `general*.bat`: программа читает из них аргументы `winws.exe` и подставляет пути, поэтому после обновления zapret новые стратегии появляются сами.
- `winws.exe` запускается как дочерний процесс в Job Object: если программа умерла (даже аварийно), winws убит системой.
- Драйвер WinDivert выгружается при остановке (только если он реально остановился и нет другого winws/службы zapret).
- TCP timestamps (нужны части стратегий) включаются на время работы и затем отключаются.
- Автозапуск — задача планировщика `Zapret Control App` (запуск с правами администратора без UAC-окна).
- Настройки: `%AppData%\Zapret Control App\settings.json`. Бэкапы старых списков при обновлении: `%AppData%\Zapret Control App\backup\`.
- Свои списки `*-user.txt` при обновлении Zapret сохраняются. Стоковые (`list-general.txt`, `ipset-all.txt` и др.) заменяются.
