## Возможности

- Включение и выключение обхода одной кнопкой, выбор стратегии из `general*.bat`.
- Автоподбор стратегии: быстрый и глубокий режимы (проверка скорости и стабильности).
- Сторожевой режим: проверка сервисов по таймеру, перезапуск после сна, смены сети и падения `winws.exe`.
- Диагностика «Почему не работает?» — проверки с понятными советами и отчёт для копирования.
- Редактор своих списков доменов и IP, которые не затираются при обновлении zapret.
- Значок в трее с цветом состояния и уведомления Windows.
- Обновление zapret и самообновление программы.
- Три темы: светлая, тёмная, зелёная.

## Первый запуск

1. Программа **всегда** требует права администратора (нужны для WinDivert).
2. Вкладка «Настройки» → указать папку Zapret. Если Zapret не установлен — указать пустую папку (без кириллицы и не в OneDrive) и нажать «Обновить Zapret» (вверху окна): скачается последний релиз.
3. Вкладка «Проверка стратегий (автоподбор)» → «Быстрый» или «Глубокий» (VPN на это время лучше выключить), по результату выбрать лучшую стратегию.
4. Кнопка «Включить».

## Режимы интерфейса

Переключатель «Продвинутый режим» находится внизу слева.

| Режим | Вкладки |
|-------|---------|
| Простой (по умолчанию) | Журнал, Проверка стратегий, Настройки |
| Продвинутый | все: добавляются Списки, Диагностика, Периодическая проверка, а в настройках — остальные параметры (например, TCP timestamps) |

Настройки, изменённые в продвинутом режиме, продолжают действовать и в простом.

## Диагностика

Вкладка «Диагностика» (продвинутый режим) по кнопке «Начать диагностику» проверяет права, папку zapret, драйвер WinDivert, конфликты с другими обходами и VPN, DNS, системное время, доступ в интернет и доступность сервисов. Каждая проверка получает статус (✓ норма, ⚠ предупреждение, ✗ проблема, ● не удалось проверить) с пояснением и советом. Отчёт можно скопировать и отправить другу или в поддержку. Диагностика ничего не меняет в системе.

## Списки

Вкладка «Списки» (продвинутый режим) — редактор файлов из папки `lists`. Свои списки (`*-user.txt`) отмечены звёздочкой и сохраняются при обновлении zapret, стоковые заменяются.

## Трей и уведомления

Значок в трее показывает состояние цветом фона логотипа:

| Цвет | Состояние |
|------|-----------|
| Серый | выключен |
| Зелёный | работает |
| Жёлтый | проблемы или нет сети |
| Красный | сбой |
| Синий | идёт автоподбор, тест или диагностика |

В меню значка: показать окно, включить/выключить, выбор стратегии, «Проверить сейчас», выход. Уведомления Windows настраиваются (выкл, только важные, все) и уважают режим «Не беспокоить».

## Как это устроено

- Стратегии берутся прямо из `general*.bat`: программа читает из них аргументы `winws.exe` и подставляет пути, поэтому после обновления zapret новые стратегии появляются сами.
- `winws.exe` запускается как дочерний процесс в Job Object: если программа умерла (даже аварийно), winws убит системой.
- Драйвер WinDivert выгружается при остановке (только если он реально остановился и нет другого winws/службы zapret).
- TCP timestamps (нужны части стратегий) включаются на время работы и затем отключаются.
- Сторожевой режим: проверка сервисов по таймеру, перезапуск после сна, смены сети и падения winws.
- Автозапуск — задача планировщика `Zapret Control App` (запуск с правами администратора без UAC-окна).
- Настройки: `%AppData%\Zapret Control App\settings.json`. Бэкапы старых списков при обновлении: `%AppData%\Zapret Control App\backup\`.
- Свои списки `*-user.txt` при обновлении Zapret сохраняются. Стоковые (`list-general.txt`, `ipset-all.txt` и др.) заменяются.

Полный перечень того, что программа делает в системе, есть в окне «О программе» (правая часть кнопки GitHub внизу).
