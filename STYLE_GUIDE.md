# Правила стилизации Zapret Control App

Эти правила обязательны для любого нового или изменяемого элемента интерфейса.

## Шрифты

Допустимы только сочетания из `Fonts` (Theme.cs). Новые не добавлять.

| Имя       | Шрифт и размер        | Где используется                                              |
|-----------|-----------------------|---------------------------------------------------------------|
| `Body`    | Segoe UI 10           | основной текст, кнопки, поля, вкладки, подписи, чекбоксы      |
| `Small`   | Segoe UI 9            | пояснения, подсказки в блоках, путь в нижней панели           |
| `Heading` | Segoe UI 11, жирный   | заголовки блоков и названия списков                           |
| `Mono`    | Consolas 10           | редакторы списков, журнал, результаты проверки                |
| `Display` | Segoe UI 14, жирный   | только кнопка «Включить/Выключить» и надпись статуса обхода   |

Для остального интерфейса — не больше четырёх сочетаний (`Body`, `Small`, `Heading`, `Mono`), пятое (`Display`) — только для кнопки и статуса.

## Размеры и сетка

- Все размеры задаются в пикселях при 96 DPI и проходят через `Ui.S()`, `Ui.Sz()`, `Ui.Pad()`. Голые числа в `Size`, `Location`, `Padding`, `RowStyle` и т.п. не допускаются.
- Базовый отступ — `Ui.Margin` (16). Левый и правый край всех блоков — на отступе 16: кнопка «Включить», первая вкладка, содержимое страниц, кнопка «Обновить zapret» и кнопка GitHub стоят на одной вертикали.
- Высота: кнопки и поля ввода 34, чекбокс 28, строка вкладок 42, нижняя панель 48, шапка 132.
- Радиус скругления везде `Ui.R` (6): кнопки, поля, выпадающие списки, списки, блоки с текстом.

## Цвета

- Только цвета палитры `Theme.Current` (Theme.cs). Произвольные цвета в элементах запрещены. Исключения: белый текст на кнопках `Accent`/`Danger` и белая галочка.
- Кнопки: `Accent` — главное действие, `Danger` — опасное, `Line` — второстепенные, `WarnBtn` — только на плашке предупреждения.
- Темы: светлая — только белое и серое; тёмная — нейтральный тёмно-серый; зелёная — тёмно-зелёная. Единственный цветной акцент — `AccentLight` (подчёркивание активной вкладки, галочки, статус «работает», прогресс).
- Новая тема или цвет — только через новый `Palette`; перекраска идёт заменой цветов старой палитры на новую (`MainForm.Theme.cs`).

## Элементы

- Использовать только свои контролы: `RoundButton`, `Check`, `Dropdown`, `TabStrip`, `ScrollText`, `SimpleList`, `ScrollHost`/`VStack`, `Note`, `ThinProgress`, `LinePanel`.
- Стандартные `Button`, `CheckBox`, `ComboBox`, `ListBox`, `TextBox` (вне `ScrollText`), `ProgressBar`, `TabControl` и системные полосы прокрутки не использовать.
- Полоса прокрутки везде одна и та же — `ThinScrollBar`: тонкий ползунок без стрелок. Колесо мыши обрабатывает `WheelFilter` для элемента под курсором.
- Системные диалоги `MessageBox` и выбор папки остаются стандартными.

## Раскладка

- `TableLayoutPanel` только с явными размерами строк и столбцов (`Cols`/`Rows`), без `AutoSize`.
- Вертикальные списки блоков — `VStack` (высоты детей задаются заранее), прокручиваемые — `ScrollHost`.

## Комментарии в коде

Только технические: почему сделано именно так, обходы ограничений Windows, неочевидные места. Без пометок «улучшили/поправили», без пояснений очевидного и без декоративных разделителей.

## Проверка перед сдачей

Элемент выглядит одинаково правильно в трёх темах и при масштабе 100% и 150%; выровнен по общим вертикалям; шрифт взят из таблицы.
